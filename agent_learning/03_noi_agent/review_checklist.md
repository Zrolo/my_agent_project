# NOI Agent 代码审查清单

> 每次修改代码后，把这份清单 + 改动内容发给 Claude 审查

---

## 审查前准备

请提供以下信息：

1. **改动范围**：修改了哪些文件？动了多少行代码？
2. **改动目的**：这次修改要解决什么问题？
3. **关键变更**：核心逻辑改动点（用文字描述）
4. **测试情况**：你自己测试过吗？结果如何？

---

## 审查维度（Claude 请按此检查）

### 🔴 P0 - 阻塞性问题（必须修复）

- [ ] **语法错误**：代码能否正常导入和运行？
- [ ] **逻辑错误**：核心功能是否与预期一致？
- [ ] **边界条件**：空值、越界、极端输入是否处理？
- [ ] **安全漏洞**：API key 是否暴露？文件操作是否安全？

### 🟡 P1 - 功能缺陷（建议修复）

- [ ] **配额逻辑**：扣减时机是否正确？能否被绕过？
- [ ] **异常处理**：错误情况是否有友好提示？
- [ ] **数据持久化**：JSON 读写是否健壮？
- [ ] **并发安全**：多窗口同时操作会不会冲突？

### 🟢 P2 - 代码质量（可选优化）

- [ ] **可读性**：命名是否清晰？注释是否充分？
- [ ] **可维护性**：函数是否单一职责？是否易于扩展？
- [ ] **性能**：是否有明显的性能瓶颈？
- [ ] **测试覆盖**：关键路径是否有测试验证？
