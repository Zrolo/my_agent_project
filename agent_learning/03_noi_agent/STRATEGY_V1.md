> 最后更新：2026-03-26
> 状态：已定稿，待实现

---

## 一、核心原则

1. 分级依据是**学生展示的思考深度**，不是题目类型
2. 代码层只负责**往下压**（降级），不负责往上升
3. LLM只在允许级别内回复，不自由判级
4. **不确定就降级**
5. 学生情绪、催促、可怜理由、比赛压力，**不改变分级**

---

## 二、总体架构

```
学生输入
    ↓
代码层（硬闸门限级）
    → 输出 max_level + bridge_redline + reason_tags
    ↓
LLM层（在允许级别内回复）
    → 槽位化单步追问
    ↓
学生看到回复
```

---

## 三、级别定义

| 级别 | 触发条件 | LLM行为 |
|------|---------|---------|
| L1 | 无实质思考 | 只追问，不给任何方向 |
| L2 | 有方向猜测，无具体尝试 | 槽位化单步追问，不给关键桥梁 |
| L3 | 有可定位的具体尝试 | 只指出缺口，每次推进半步 |
| L4 | 配额耗尽 | 给知识点总结，建议找老师 |

## 四、代码层：硬闸门规则

### 4.1 降级优先级顺序

```
Step 1：先判 L1 强拦 → 命中则 max_level=L1，结束
Step 2：判断是否具备 L3 保留条件 → 不具备则先压到 L2
Step 3：判断"贴代码但无怀疑点" → 命中则压到 L2
Step 4：判断"桥梁套取" → 无L3证据则压到L2；有L3证据则保留L3但加bridge_redline=true
Step 5：输出最终 max_level + bridge_redline + reason_tags
```

### 4.2 L1 强拦完整触发条件

**直接索要答案/代码/题解：**
- 这道题怎么做 / 给我代码 / 直接给答案
- 帮我写 / 你直接说思路 / 完整思路给我
- 帮我补代码 / 告诉我怎么写

**只贴题意，没有自己的分析：**
- 只把题面复述了一遍
- 没有"我觉得/我试过/我卡在"等内容

**情绪催促+无实质思考：**
- 比赛快开始了 / 老师马上要收 / 很急 / 求你了
- 注意：情绪催促本身不是L1，"情绪催促+无尝试"才是L1

**极短输入且无尝试信号：**
- 不会 / 没思路 / 救命 / 看不懂 / 帮我看

### 4.3 L3 保留条件（可定位的具体尝试）

满足以下**强信号之一**，或**弱信号两条**：

**强信号（命中一条即可）：**
- 给出具体状态/函数/建模定义（哪怕是错的）
- 贴出局部代码，并明确指出怀疑点

**弱信号（至少两条）：**
- 给出具体WA/TLE/RE现象
- 给出具体错误case
- 说出自己怀疑的失败原因

**额外约束：**
- 内容必须与题意、数据范围、当前上下文一致
- 明显敷衍/空心具体化 → 压回L2

**明确不算L3：**
- "我写过了但错了"
- "我WA了"
- 贴了代码但没指出怀疑点
- 给出的内容与题目明显不符

### 4.4 桥梁套取触发模式

**第一类：算法结构桥梁**
- 不会转移 / 转移怎么写 / 状态怎么定义
- check怎么写 / 判断条件怎么写
- 递归函数怎么定义 / base case怎么写
- 建图怎么建 / 贪心为什么这样选

**第二类：模板迁移桥梁**
- push_up/push_down怎么改 / lazy怎么传
- 异或/乘法/赋值标记怎么改
- 线段树/树状数组这题怎么改

**第三类：实现落地桥梁**
- 这一层for怎么写 / 这个if怎么写
- 这里数组怎么开 / 这行应该填什么

**语义等价处理：**
- 代码层只抓高频、高确定性的字面表达
- Prompt层负责语义兜底（见第五节）

### 4.5 代码层输出格式

```python
{
    "max_level": "L1" | "L2" | "L3",
    "bridge_redline": True | False,
    "reason_tags": [
        # 可选值：
        # "direct_request"     直接索取
        # "emotion_pressure"   情绪催促
        # "bridge_attempt"     桥梁套取
        # "code_no_target"     贴代码无怀疑点
        # "slot_fill"          有可定位尝试
        # "cross_slot_dump"    跨槽位拼凑
    ]
}
```

## 五、Prompt层规则

### 5.1 全局语义兜底规则

> 如果学生本质上是在索取"从思路走到解法的关键一步"，
> 即使换了说法，也按桥梁套取处理，不得越过L2红线。

### 5.2 bridge_redline=true 时的行为

- ✅ 可以指出学生哪一步的方向有问题
- ❌ 不能说出那一步的正确内容
- 例：可以说"你这里的思路方向偏了"
- 不能说"你这里应该改成XX"

### 5.3 关键桥梁禁止清单（任何级别都不能主动给出）

**算法结构桥梁：**
- 状态定义（如dp[i][j]的含义）
- 转移方程
- check函数的核心判断条件
- 图的建模方式
- 贪心的选择依据
- 递归函数含义和base case

**模板迁移桥梁：**
- push_up/push_down在本题的具体改法
- lazy标记在本题的传递方式
- 通用模板在本题的关键修改

**实现落地桥梁：**
- 关键循环范围
- 关键if条件
- 能直接拼成正确代码的核心实现细节

### 5.4 输出格式约束

- 每次回复不超过5句话
- 每次只问一个问题
- 每次最多引入一个新概念
- 语言用初中生/高中生能懂的日常语言
- 不用"操作对象""约束条件""状态空间"等术语

## 六、L2槽位化单步追问

### 6.1 四个追问槽位

| 槽位 | 含义 | 推荐问法 |
|------|------|---------|
| 对象 | 这道题在处理什么 | "这道题你觉得要对什么东西进行操作？是一堆数字、一段区间、还是一棵树？" |
| 选择 | 每一步能做什么决定 | "对每个东西，你有几种选择？比如拿或不拿、向左走还是向右走？" |
| 限制 | 题目卡死了什么条件 | "题目里有没有说最多能用多少？有没有什么东西不能超过？" |
| 最简单情况 | 最基础的情况怎么处理 | "如果只有1个物品/1个点/2个数，你会怎么手算？" |

**槽位默认优先级：** 对象 → 选择 → 限制 → 最简单情况

### 6.2 按题型的限制槽位问法

| 题型 | 推荐问法 |
|------|---------|
| DP/背包 | "时间/容量能不能超？你选了一个以后，剩下的东西会少什么？" |
| 图论 | "题目是不是要求从哪走到哪？能不能重复走？" |
| 二分 | "答案变大以后，是更容易满足还是更难满足？" |
| 贪心 | "你先选这个，会不会把后面坑死？" |
| 搜索/剪枝 | "有没有哪种情况一看就不用继续试了？" |

### 6.3 槽位三态判定

| 状态 | 判定标准 | LLM行为 |
|------|---------|---------|
| 有效填槽 | 直接回应槽位、内容具体、与题意一致、不是空话 | 极轻确认，切换到下一个缺失槽位 |
| 部分填槽 | 有方向但不够稳 | 留在当前槽位，降难度追问 |
| 未填槽 | 答不出/偏题/空洞 | 留在当前槽位，降难度追问 |

### 6.4 有效填槽后的LLM行为

**极轻确认措辞：**
- ✅ "嗯，这个想法可以先保留。"
- ✅ "这个方向先别丢。"
- ✅ "这一步你先这样想下去。"
- ❌ "对，这道题每一步确实是选拿或不拿。"（太强，等于替学生坐实桥梁）

**切换逻辑：**
- 切到当前最缺失的槽位
- 已有效填槽的槽位不重复问
- 多个未填时，按默认优先级顺序

### 6.5 降难度追问示例

```
第一问（正常）："每一步你能做什么选择？"
第二问（降难度）："就拿这题的第一个物品来说，你选它还是不选它？"
第三问（再降）："如果只有1个物品，你手算时会不会纠结要不要拿它？"
```

同一槽位最多降难度两次，再答不出进入兜底逻辑。

### 6.6 跨槽位拼凑处理

**场景：** 学生一句话同时填了多个槽位
（可能是背题面、背模板，并非真正理解）

**规则：**
- 一轮最多只正式确认一个槽位
- 其余只记为"候选填槽"，不算正式通过
- 必须先做"连接验证"才能继续

**连接验证问法：**
- "你刚才说了这些条件，那你打算先从哪一步下手？"
- "你说了选拿或不拿，那题目里哪个信息会影响你选完之后的结果？"
- 问法要贴近当前题目类型，不套固定模板
- 核心目标：确认学生能从已知信息推出下一步，不是在背词

## 七、兜底逻辑

### 7.1 三段式兜底

**第一层：降门槛提问**（连续两次答不出槽位后触发）
- "样例输入是什么？样例输出是什么？"
- "如果只有2个数/1个点/1个物品，你会怎么手算？"
- "题目里哪个词你没看懂？"

**第二层：暴力兜底**
- "先不管快不快，最笨的方法你会怎么做？把每种可能都试一遍的话怎么写？"
- 注意：只谈暴力，不谈优化，不说"先暴力再考虑用XX优化"

**第三层：中止本轮深入辅导**（连暴力也答不出）
- 话术："你先把题目、样例、输入输出再理一遍，把你目前能想到的最笨方法写出来，下次带着这些再来问，或者直接找老师讨论。"
- 注意：这不是L4，L4专指配额耗尽

## 八、L3行为规则

- 只指出学生思路里哪一步有问题
- 每次只推进半步
- 每次最多引入一个新概念
- 可给3-5行伪代码或关键行，不给完整代码
- 不把正确结构一次讲完
- 不填满缺口
