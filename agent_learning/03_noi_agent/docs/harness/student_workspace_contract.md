# 学生端工作台契约

## 本文件的写入标准

只写学生端工作台的稳定契约：

- 页面层级
- 区块职责
- 阶段状态
- 响应式规则
- 上下文切换规则

不要写：

- 具体 CSS 细节
- 某个瞬时 UI bug
- 临时视觉方案

---

## 一、学生端一级入口

学生端只有两个一级入口：

1. `AI 解答`
2. `打卡复盘`

### 含义

- `AI 解答`：适合先问局部问题、确认一小步、快速求助
- `打卡复盘`：适合正式提交一条错题 / 卡点记录，并进入统一复盘工作台

---

## 二、复盘工作台的三区结构

复盘工作台采用三段式：

### 左侧：提交与历史

职责：

- 新建打卡
- 查看最近历史记录
- 切换当前工作台上下文

左侧历史记录的角色是：

> **上下文选择器**

不是单纯的“历史展示列表”。

点击历史记录后，应更新：

- 中间区的小测 / 学习状态
- 右侧区的复盘 / 同类题 / 同题 AI 摘要

### 中间：理解检查区

职责：

- 当前 quiz
- self-check
- remedy

这是学生实际“练这一步”的主区域，不是结果说明区。

### 右侧：解释与迁移区

职责：

- AI 复盘内容
- 同题最近 AI 解答摘要
- 同类题推荐

这是学生优先阅读的解释区。

---

## 三、工作台阶段状态

以下内容是工作台内部状态，不是页面级模块：

- 空态
- 复盘待生成
- 复盘已生成
- 小测进行中
- self-check
- remedy_available
- remedy_in_progress
- resolved
- needs_teacher_followup

### 规则

学生无论处于哪个阶段，都仍然停留在同一个复盘工作台中。

不能把：

- 小测进行中
- 复盘已生成
- 补救中

再拆成新的 tab 或新的页面入口。

---

## 四、AI 解答 与 复盘工作台的数据关联

`AI 解答` 和 `复盘工作台` 不是两套完全断开的数据。

### 当前约束

如果学生先在 `AI 解答` 中针对某道题提问，再在 `打卡复盘` 中提交同一道题：

- 系统允许提取“同题最近 AI 解答摘要”
- 在复盘时把它作为辅助线索带入

### 但要注意

这条摘要：

- 只能是辅助上下文
- 不能替代本次卡点描述
- 不能替代本次错误类型
- 不能替代本次代码 / 提交现象

---

## 五、左侧表单规则

### 洛谷题

当来源为洛谷，且学生输入有效题号/链接时：

- 系统自动补：
  - 标题
  - 题面
  - 标签
  - 难度（如可得）

此时：

- 不再要求学生手填题面原文
- `题意补充` 只保留为可选项

### 非洛谷 / 未命中

仍然要求：

- 手动填写 `problem_context`

---

## 六、工作台切换规则

### 新提交打卡后

提交成功后，页面应：

1. 保持在 `打卡复盘` 工作台
2. 自动切到这条新记录的上下文
3. 右侧开始显示复盘状态
4. 中间开始显示当前理解检查状态

### 查看历史记录时

切换到某条历史记录后：

- 右侧加载该条复盘
- 中间加载该条 quiz / self-check / remedy 状态
- 左侧高亮当前选中的历史记录

---

## 七、响应式规则

### 桌面端（宽屏）

保留三段并排：

- 左：提交与历史
- 中：小测 / self-check / remedy
- 右：AI 复盘 / 同类题

### 中等屏幕

- 左侧收窄
- 保留中右主区

### 移动端

单栏顺序固定为：

1. 右侧解释区
2. 中间理解检查区
3. 左侧提交与历史区

原因：

- 学生通常先看解释，再做题，而不是先做题再找解释

---

## 八、视觉层级原则

学生端优先强调：

1. 当前正在做的任务
2. 当前这条复盘的解释
3. 当前这一步的小测

弱化：

- 系统状态碎片
- 次要标签
- 辅助说明

### 文字层级

优先保证字体层级清晰，再谈颜色层级。

建议至少保持三级：

- 一级：当前任务标题 / 小测标题
- 二级：关键桥梁 / 区块标题 / 状态标签
- 三级：历史摘要 / 辅助说明 / hint

---

## 九、交互约束

1. hover 行为要统一：
   - 表单块 hover 高亮
   - 历史卡 hover 抬起
   - quiz 选项 hover 高亮

2. 长文本不能撑破容器：
   - 标题
   - 标签
   - quiz 题干
   - 复盘正文
   - 同类题标题

3. 点击历史记录不应导致工作流丢失：
   - 只是切换上下文，不是跳离工作台
