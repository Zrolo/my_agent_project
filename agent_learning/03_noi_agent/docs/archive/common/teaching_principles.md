# 教学原则

这份文档只记录跨学科可复用的教学原则，不写具体学科术语。

## 当前共识

### 1. Quiz 不是考试，而是桥梁验证
- 核心问题不是“学生能不能答对”
- 而是“学生原来卡住的那一步，现在到底会不会了”

### 2. 不能把答对一次当成掌握
- 首轮答对不等于真的懂
- 需要通过自评、confirm、老师端证据链一起判断

### 3. 不要教太满
- 系统不能抢在学生前面直接报答案、算法名或完整路径
- 补救的目标不是替学生走路，而是扶着他自己走一步

### 4. 对学生的反馈要区分答对和答错
- 答对：告诉学生“你刚才真正答对了哪一步”
- 答错：告诉学生“你选的这个为什么错”

### 5. 过程证据比结果更重要
- 老师需要看到学生是怎么过桥的
- 不能只看最后“过了/没过”
