# 产品红线

这份文档记录评审任何新功能时都要先过的一组“不能碰”的边界。

## 当前红线

1. 不能把产品做成开放聊天型 AI 主入口
2. 不能在学生做任何判断前，先把答案、算法名或完整路径给出来
3. 不能把 quiz 只做成“口号判断题”
4. 不能只记录结果，必须留下过程证据
5. 不能把练习做成题海，优先练桥梁
6. 不能用系统内部术语替代学生能懂的话
7. 不能为了“更智能”牺牲边界清晰和状态可恢复性

## 评审时固定要问的问题

- 这个功能是在帮助学生自己起步，还是在替他起步？
- 这个功能会不会鼓励学生装懂？
- 老师最后能不能看懂“这次到底是怎么过桥的”？
- 这条交互对初中生是不是太抽象了？
