# Quiz 设计模式

这份文档专门记录“什么样的 quiz 有教学价值，什么样的没有”。

## 当前有效模式

### 1. 结构型小题
- 直接让学生判断定义 / 转移 / 条件 / 顺序
- 不再抽象地问“这一步更该做什么”

### 2. 答对 / 答错分流反馈
- 答对：`bridge_feedback`
- 答错：`distractor_feedback`

### 3. 分层验证
- `main`：原题语境
- `followup`：原题语境但更小
- `confirm`：更小新情境，验证迁移

## 当前反模式

### 1. 抽象口号题
- 例：`这一步更该先做什么？`
- 风险：学生只是猜老师想听哪句

### 2. 计算题伪装成结构题
- 例：让学生算具体数值、节点编号、最终答案
- 风险：测的是算数，不是桥梁理解

### 3. 答错后直接灌完整正确答案
- 风险：学生知道标准答案，但不知道自己刚才错在哪
