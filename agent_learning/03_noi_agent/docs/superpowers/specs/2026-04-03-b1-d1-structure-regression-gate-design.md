# B1 / D1 结构断言式回归门设计

## 目标

把 `constraint_modeling` 的 `B1` 和 `method_selection` 的 `D1` 从“固定短词命中”收紧为“结构主规则 + 少量辅助词兜底”。

这次设计只解决一件事：

- 让回归测试先判断桥梁有没有说对
- 再判断学生能不能看懂、能不能立刻开始下一步

本 spec 不改 `review_engine.py`，只定义后续如何调整 `test_review_regression.py`。

---

## 一、设计原则

1. 回归通过不能只靠关键词命中。
2. 必须先满足结构主规则，才允许进入辅助词兜底。
3. `next_step` 必须是具体动作，且动作的输入和输出都能在文本里看出来。
4. 如果输出里没有任何一句直接对应原题具体对象，判失败。
5. 辅助词只做宽松兜底，不能反过来主导判定。

---

## 二、B1 规则

### 场景意图

`B1` 测的不是学生会不会算法名，而是学生有没有看出：

- 时间条件
- 地点条件

这两个限制是并列关系，必须同时成立。

### 结构主规则

1. `key_bridge` 或 `main_block` 必须明确表达“两个条件都要成立”。
2. 输出里必须明确表达两个条件是平级的，例如并列列出、同时提到、各自独立说明。
3. 如果输出呈现的是“先满足 A，再检查 B”的顺序结构，直接判失败，不进入辅助词兜底。
4. `next_step` 必须给出一个立刻可做的动作，例如：
   - 把两个条件分别列出来
   - 拿一个样例逐项检查
   - 画 `2 x 2` 的真假组合
5. 如果输出只是说“这是逻辑与关系”但没有贴题解释和动作，不算通过。
6. 如果输出主要是“再仔细审题”“多想想条件关系”这类空泛建议，不算通过。

### 人话规则

1. 输出应尽量用学生能听懂的话，例如“两个条件都得过，少一个都不行”。
2. 不应主要依赖术语堆砌，例如整段都在说“逻辑与、布尔表达式、维度编码”。
3. 学生看完后，应该能直接回答“我下一步先做什么”。

### 辅助词兜底

只保留少量宽松词：

- `同时`
- `都要`
- `两个条件`
- `都满足`

### 典型失败例

- `先看时间，再顺便检查地点`
- `这是逻辑与关系，应做联合判定`
- `你再仔细审题`
- `时间条件和地点条件都要看，但先把时间条件排除掉不满足的`

---

## 三、D1 规则

### 场景意图

`D1` 测的不是学生会不会说 `DP`，而是学生有没有先看规模信号，再决定方法。

### 结构主规则

1. `key_bridge` 或 `main_block` 必须明确表达“先看规模 / 范围，再决定方法”。
2. 输出里必须能看出“这里可以直接枚举”或“没必要先上 DP”这一层判断。
3. `next_step` 必须给出一个立刻可做的动作，例如：
   - 先确认 `n` 的范围在哪里，例如 `n <= 20`
   - 先算 `2^20`
   - 先估总状态数
   - 先写出要枚举的对象是什么
4. 如果输出一上来就报算法名，而没有经过规模判断，不算通过。
5. 如果输出只是“考虑 DP / 搜索 / 枚举”这类泛方法建议，不算通过。

### 人话规则

1. 输出应让学生明白“为什么这题先不用 DP”。
2. 不应主要是术语化表达，例如“由规模信号导向子集枚举策略”。
3. 学生看完后，应该能直接知道自己现在第一步要算什么、看什么。

### 辅助词兜底

只保留少量宽松词：

- `2^20`
- `2^n`
- `枚举`
- `子集`
- `规模`
- `范围`
- `不必先想 DP`

### 典型失败例

- `这题考虑 DP`
- `可以搜索或动态规划`
- `先复习枚举模板`
- `先估一下规模，如果太大就用 DP`

---

## 四、实现边界

后续落到 `test_review_regression.py` 时，按下面边界执行：

1. `B1 / D1` 采用独立判定函数，不再只复用通用词表命中逻辑。
2. 主判定顺序固定为：
   - 先判结构主规则
   - 再判是否贴原题对象
   - 最后再看少量辅助词
3. 辅助词只能加分，不能单独救活结构错误输出。
4. 失败例要能直接转成反例测试，防止以后又被辅助词误救。
5. 这轮只调整 `B1 / D1`，不顺手重写其它 case。

---

## 五、验收口径

如果这套规则落地后，满足下面三点，就算这轮方向成立：

1. `B1 / D1` 对“正确但不同说法”的输出容忍度更高。
2. `B1 / D1` 对“术语命中但结构仍然错误”的输出拦截更稳。
3. 回归门更贴近“初中生能否听懂、能否行动”，而不是“有没有背出标准术语”。
