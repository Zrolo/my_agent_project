## 从这 10 个 case 抽出的修 prompt 方向

1. **Bridge Contract 原始生成要降强度**：它质量高，但经常把 micro-example 做成完整 worked example，导致学生只是在读答案。
2. **Guard 要识别“微型例子说穿关键桥”**：即使没有完整代码或完整题解，只要例子完整演示了当前 missing bridge，也要判为 leakage。
3. **Repair 要保留教学质量**：修复不能只把答案删成空问题；需要保留一个具体、可操作的小任务。
4. **算法确认类要少盖章**：如 Dijkstra、trie、二分方向，尽量让学生用题面条件或样例自己验证。
5. **例子必须可区分**：哈夫曼、01 背包、二分 check 这类例子如果数值选错，会比泄露更糟糕。
