🎯 我们在做什么
  构建一个防止学生依赖AI的NOI竞赛教练Agent，核心机制是：
  - 学生不展示思考 → 只反问（L1，不扣配额）
  - 学生展示思考 → 给方向提示（L2，扣1次）
  - 仍卡住 → 给代码片段（L3，扣1次）

═══════════════════════════════════════════════════════════════════

✅ 已完成（代码已推送到GitHub）

  1. 配额系统
     - 每道题独立3次配额
     - 绑定维度：学生ID + 题目ID
     - 存储：本地quota.json

  2. 级别判定（核心逻辑）
     - 优先：读取LLM回复末尾的[LEVEL:Lx]标签
     - 备用：检测代码块（```）判定为L3
     - 保守：其他情况不扣配额

  3. 对话管理（刚修复）
     - display_reply：带配额提示，给学生看
     - history_reply：干净内容，存messages（解决重复提示问题）
